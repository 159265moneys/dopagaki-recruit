# ドパガキ採用 — 株式会社next マーケティング職 採用サイト

「ドパガキが隅から隅まで触ってしまう」ことに全振りした採用サイト。

## 遊べる仕掛け

| 場所 | 仕掛け |
|---|---|
| FV | ドパミンスロット（3リール／リーチ演出／“おしい”を意図的に量産するスベリ実装） |
| 01 | 5秒連打耐久ミニゲーム＋社内ランキング |
| 02 | WHYカード（クリックで裏返る） |
| 03 | ドパガキ検定（全8問→6タイプ判定→結果画像を canvas 生成／Xシェア） |
| 04 | 数字カード（全部クリックで裏の真実が出る） |
| 05 | 社員カード（クリックで裏／長押しで隠しコメント） |
| 06 | 募集要項（真面目パート）＋「読んだフリをする」ボタン |
| 07 | 「押すな」ボタン（20段階のリアクション） |
| 08 | YOUR LOG（滞在中の行動を全部開示 → ネタバラシ） |
| EX | 隠しセクション（ドパ玉10個コンプリートで解放） |

### 常時稼働
- **ドパ玉10個**（HUDの 🧠 x/10）— サイト各所に隠されている。コンプリートで隠しページ解放
- **DP経済＋レベル**（Lv.1 無 → Lv.8 人間をやめた）
- **踏破率メーター**（セクション到達＋仕掛け接触で 0→100%）
- **リアルタイム観測トースト**（👁 スクロール速度・離脱・戻り・連打などを実測して煽る）
- **Web Audio 完全合成**の BGM（124BPM）と SE。音源ファイルは0個
- **three.js 背景** — ドーパミン C8H11NO2 の分子構造を実際の結合どおりに構築＋パーティクル＋UnrealBloom

### 隠し要素
1. ローディング画面の会社名　2. スロット筐体のネジ　3. 連打ランキング最下位の名前
4. WHYカード3枚目の裏　5. 数字セクションの「※」　6. 募集要項の「※」
7. フッター巨大文字の「ガ」　8. コナミコマンド（↑↑↓↓←→←→BA）
9. 開発者コンソールで `dopa()` を実行　10. 「押すな」ボタンを15回押す

さらに：ロゴ3連打／ヒーロー文字の1文字クリック／タブを離れるとタイトルが書き換わる。

## プライバシー

行動計測は **すべてブラウザ内で完結** し、外部送信は一切行いません。
保存も `localStorage`（ドパ玉とDPのみ）です。

## 差し替えが必要な箇所（★重要）

現在はすべて**掲載サンプル**です。公開前に実データへ差し替えてください。

- `index.html` の `data-need-url` が付いたリンク（応募フォーム／カジュアル面談／会社紹介資料のURL）
- `index.html` の募集要項（給与・勤務地・勤務時間など）
- `assets/js/content.js` の `NUMBERS`（数字で見るnext）
- `assets/js/content.js` の `PEOPLE`（社員プロフィール）
- `assets/js/content.js` の `initBurst` 内、社内ランキングの記録（78回 / 61回）
- OGP画像 `assets/img/ogp.png`（未配置）

## 開発

静的サイト。ビルド不要。ES Modules を使うので `file://` では動きません。

```bash
python3 -m http.server 5178
```

`three.js` r160 と postprocessing addons は `assets/vendor/` にベンダリング済み（CDN依存なし）。
Webフォントのみ Google Fonts を参照します。
